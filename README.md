₹0–20 | ₹20–40 | ₹40–60 | ₹60–80 | ₹80–100

The scanner finds fundamentally strong stocks with a 20–45 session base, support, pullback/reversal and momentum confirmation. It does not pretend Yahoo Finance provides a reliable live NSE option chain.

Before selling any PE, verify live NSE premium, OI, IV, volume, bid/ask, expiry and hedge price. Prefer a defined-risk bull put spread.
